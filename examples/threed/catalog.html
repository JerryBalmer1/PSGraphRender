forcegraph3d variant catalogue

19 labelled looks for the 3D backend, in 5 families. Every one is ONE overlay of declared settings away from A0, which is what the backend ships with no configuration at all — so any two pictures here differ by exactly the keys named under them.

All of them draw the same payload, input/ecosystem-viewmodel.json, so the only variable is the overlay. Generated from examples/threed/variants.psd1 by examples/Build-Examples.ps1 -Variant all; this page is never edited by hand.

A screenshot cannot show a zoom speed or a hover. The D family is here for its labels and its captions; open the page to use it.

A — shape and size

A0 The default
Nothing. This is what New-RenderDocument -TemplateSet forcegraph3d produces with no overlay, and every other variant is a diff from it.
no overlay - this is the default

NodeSizeMetric = blastRadius. Radius follows how much breaks if this changes, by rank.

A2 Size by reach, harder
NodeSizeMetric = reach and NodeSizeMetricMax 2.6 -> 4.5, so the spread between smallest and largest is wider.

A3 Every classification its own solid
KindShape names all four of this payload's classifications instead of two, so nothing falls back to a sphere.

A4 Shape channel off
KindShape empty, so every item takes NodeShapeFallback. What the backend drew before v0.16.0, on the new scene.
